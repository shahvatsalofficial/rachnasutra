# FAQ and glossary

## Frequently asked questions

### Do I need an API key or an AI subscription?

No for the CLI. The skills run on whichever AI IDE you already use and its model, so you need access to that IDE, not to a RachnaSutra account.

### Does it send my code anywhere?

The CLI makes no network requests and has no telemetry. If you use the skills in an AI IDE, that IDE's provider processes what the assistant reads, under your agreement with them.

### Will it make my site WCAG compliant?

No tool can promise that. RachnaSutra finds a set of common issues and gives evidence and fixes. Conformance needs manual testing, ideally with assistive-technology users, and often a specialist review.

### What does "0 findings" mean?

That the 26 static rules found nothing in the files scanned. It does not mean the interface is accessible. See [Legal and compliance](09-legal-and-compliance.md).

### Why is there no score?

Most categories are only partly evaluated by static analysis. A score would reward a narrow scan. Coverage is shown instead.

### Why do I get `review-required` findings?

They are heuristic. For example, a form field without a visible label might get its label from a component wrapper. A person should confirm.

### Can I run it on a framework like React, Vue or Next.js?

It reads JSX, TSX, Vue, Svelte and Astro source and CSS files. It cannot see markup produced at runtime or styles generated by CSS-in-JS and utility frameworks.

### Why does `visual` or `--mode browser` exit with code 3?

Those features are not implemented yet. The tool says so instead of producing a fake result.

### Which AI IDEs are supported?

Claude Code, Cursor, OpenAI Codex and GitHub Copilot have adapters that follow documented layouts, and Gemini CLI is experimental. None has been smoke-tested live yet. Other hosts can use a manual copy of `skills/`.

### Will uninstall delete my changes?

No. Uninstall removes only files whose content still matches what was installed.

### Can I use it commercially?

Yes, under Apache-2.0. Keep the licence and `NOTICE`. See [Legal and compliance](09-legal-and-compliance.md).

### How do I add or change a rule?

See the [Maintainer handbook](13-maintainer-handbook.md).

### How is this different from axe, Lighthouse or WAVE?

Those tools run against rendered pages. RachnaSutra currently analyses source files, runs offline, and adds agent skills for the review, redesign and verification workflow. They are complementary; runtime tools will be integrated as optional modules later.

### Is there a hosted version?

No. There is no account, server or telemetry.

## Glossary

| Term | Meaning |
|---|---|
| Agent Skill | A folder with a `SKILL.md` that teaches an AI assistant a task |
| Prime | The orchestrator skill, `rachnasutra-prime` |
| Finding | One reported issue with location, evidence, impact and fix |
| Confirmed | Detected by a deterministic pattern or measurement |
| Review required | A heuristic signal needing human confirmation |
| Not run | A check that was not performed; never counted as passed |
| Coverage | The table showing what was and was not evaluated |
| Fingerprint | A short hash identifying a finding across runs, used for baseline comparison |
| Baseline | A saved report to compare future audits against |
| SARIF | Static Analysis Results Interchange Format 2.1.0, accepted by GitHub code scanning |
| WCAG | Web Content Accessibility Guidelines; this project targets 2.2 level AA as a reference |
| Success criterion | One numbered WCAG requirement, such as 1.4.3 Contrast (Minimum) |
| Contrast ratio | A measure of luminance difference between text and background; 4.5:1 is the AA minimum for normal text |
| Design token | A named design value such as a colour, spacing step or radius |
| Reflow | Content adapting to narrow viewports without two-dimensional scrolling (320 CSS px) |
| Core Web Vitals | Google's LCP, INP and CLS user-experience metrics; not measured in 0.1.0 |
| Host adapter | Code that installs skills into a specific AI IDE's folder layout |
| Install manifest | The file recording installed paths and hashes at `.rachnasutra/install-manifest.json` |
| Static analysis | Examining source text without running the program |
| Dark pattern | An interface design that manipulates users against their interests |
| Vestibular disorder | A balance-system condition that motion on screen can aggravate |
| Native mode | Reasoning done by the AI IDE's own authenticated model |
