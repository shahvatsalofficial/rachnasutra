# CLAUDE.md

See [AGENTS.md](AGENTS.md) for the shared rules.

For UI/UX review, accessibility, responsive or design-system work in a project, use the `rachnasutra-*` skills, starting with `rachnasutra-prime`. Canonical skills are in `skills/`; installed copies are generated by `rachnasutra skills install --host claude`.

Working rules for this repo:
- Run `npm test` before claiming a change works, and report real results.
- Do not edit generated `dist/`.
- Do not claim WCAG conformance, host compatibility or measured performance without evidence.
